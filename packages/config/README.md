# @scope-ai/config

Loading and validating SCOPE configuration: scope.yaml, workflow files and datasets, with file:line:column diagnostics, templating and JSON Schemas for editors.

This package is part of [SCOPE](https://github.com/tanmaytyagii/scope) — open-source tracing,
evaluation and regression testing for AI workflows. Most people want the CLI
(`npm install -g scope-ai`) or the tracing SDK (`@scope-ai/sdk`) instead.

Apache-2.0.
