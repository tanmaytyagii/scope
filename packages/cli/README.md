# @scope-ai/cli

The `scope` command of [SCOPE](https://github.com/tanmaytyagii/scope): run and evaluate AI
workflows, inspect traces, compare runs, gate CI on regressions, and serve the dashboard.

```bash
npm install -g scope-ai        # or: npx @scope-ai/cli --help
```

See the [CLI reference](https://github.com/tanmaytyagii/scope/blob/main/docs/guides/cli.md) and the [quickstart](https://github.com/tanmaytyagii/scope/blob/main/docs/guides/quickstart.md).
`main(argv)` is exported for embedding the CLI in other tools.

Apache-2.0.
