# scope-ai

**SCOPE — see what your AI actually does.** Open-source tracing, evaluation and regression testing
for AI workflows. This package installs the `scope` command.

```bash
npm install -g scope-ai
scope init support-bot && cd support-bot
scope run          # run, trace and evaluate the example workflow (offline, no API key)
scope ui --open    # the dashboard at http://127.0.0.1:4700
```

Requires Node.js 22.16 or newer. Documentation: [quickstart](https://github.com/tanmaytyagii/scope/blob/main/docs/guides/quickstart.md) ·
